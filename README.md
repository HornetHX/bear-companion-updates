# 一二布布 · 口袋陪伴

安卓桌面宠物 App 的公开安装包与更新索引。

## 下载与安装

从 [最新版本发布页](https://github.com/HornetHX/bear-companion-updates/releases/latest) 下载 APK，直接覆盖安装即可，无需先卸载旧版。

v1.2.1 起，小窝底部新增「关于与更新」。先手动安装这一版一次，之后可在 App 内「检查更新 → 下载并安装」。首次更新需要允许此应用安装更新包，并在 Android 系统窗口确认安装。

## 下载加速

App 使用 CDN 更新索引以及多条安装包下载线路，下载前小流量测速，持续低速时自动换线。最终安装仍校验大小、SHA-256、包名、版本和原签名。手机不需要 GitHub 账号，App 不保存访问令牌。

该仓库仅放安装包、版本说明和 latest.json，源码保存在私有仓库。宠物存档与显示设置保存在手机本机。
